# soroban-shield-tests

Fuzz harnesses, property-based tests, and integration suites for Soroban Shield.

## Layers

| Layer | Crate | Command |
|-------|-------|---------|
| Fuzz | shield-fuzz-harnesses | `make fuzz` |
| Property | shield-property-tests | `make property` |
| Integration | shield-integration-suites | `make integration` |

## Quick start

```bash
make test
```
